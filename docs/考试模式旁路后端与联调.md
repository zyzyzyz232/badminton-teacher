## 2. 启动旁路

前提：本机 Redis（`D:\Java_Files\Redis\`）、JDK 8、Maven 3.9。

```text
cd yudao-boot-mini
mvn -pl yudao-server -am package -DskipTests

# 必须先停掉占用 48081 的旧进程，再启动，否则 Windows 锁 jar / 仍跑旧代码
java -jar yudao-server/target/yudao-server.jar
```

不要在父 POM 上执行无插件前缀的 `spring-boot:run`。Profile 为 `local`，端口 `48081`。

考试路径已 `permit-all`；`yudao.api-encrypt.enable: false`。本地上传目录：`yudao-boot-mini/file-storage`。

## 3. 表与查数

考试资料在 **`teaching_exam_item_material`**，不要和教学模式的 `teaching_item_material` 搞混。

| 表 | 用途 |
|----|------|
| `teaching_exam` | 考试头表（`lesson_id` 与考试课堂 1:1，`score_ratio`） |
| `teaching_exam_item` | 考核项（`exam_id`、`algo_type`、`sort_order`） |
| `teaching_exam_item_material` | 考核项图片/视频元数据 |

现网 `plan-material/upload` 可能顺带往 `teaching_item_material` 插一行（现网接口副作用）。以考试表是否有 `video_url`/`image_url` 为准。

---

## 4. 上传链路（勿再走七牛）

教学模式：**不走**芋道 `FileApi`，文件落在现网磁盘 `pic-video`。

考试模式曾把 multipart 打到旁路 `FileApi` → 主配置「七牛示例桶」→ S3 403 → 前端「系统异常」，`teaching_exam_item_material` 无行。

当前策略：

1. 小程序优先 `POST 48080/teaching/plan-material/upload`（与教学相同），再 `GET get` 或 `list-by-item` 取 URL。  
2. 失败则 `POST 48081/teaching/exam-item-material/upload`（本地落盘，URL 形如 `http://<本机>:48081/admin-api/teaching/exam-item-material/file/<uuid>`）。  
3. 再 `POST 48081/teaching/exam-item-material/create` 写考试资料表。

改完 Java 必须 **重新 `package` 并重启 jar**。只重启旧 jar 仍会打七牛。

## 5. 前端注意点

| 问题 | 处理 |
|------|------|
| 微信 picker 的 `e.detail.value` 是字符串 | 课堂类型必须 `Number(...)`，否则 `"1"+1` → `"11"`，考试课堂会存成普通课堂 |
| 课堂列表 `type=2` | 进入考试项配置，不要进训练计划选择 |
| 创建考试拉课堂 | `GET /teaching/course/list-lessons` 打 **48080**，不要打 48081 |
| 进入考场 | 阶段一：至少 1 个考核项；**资料选填**；项内权重合计建议 100% |
| 本机 IP 变化 | 只改 `examApi.js` 的 `TEACHING_API_BASE`；微信开发者工具需允许该 upload/download 域名（开发版可关校验） |

## 6. 阶段一自测

1. 建考试课堂（`type=2`）→ 建考试占比 40 → 列表可见。  
2. 再建物占比 70 → 失败（剩余 60）；再建 60 → 成功。  
3. 加考核项 → 上传图片/视频 → `teaching_exam_item_material` 有行，前端可预览。  
4. 无考核项点「进入考场」→ 拦截；有项无资料 → **允许**（toast 阶段二再开放）。
