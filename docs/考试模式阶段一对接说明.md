## 2. 页面 ↔ API 对照

### 2.1 考试头表 `teaching_exam`

| 前端方法 (`examApi.js`) | 方法 | 路径 | 主要参数 / 期望 |
|-------------------------|------|------|-----------------|
| `fetchExamListByCourse` | GET | `/teaching/exam/list-by-course` | `courseId` → `data: ExamVO[]` |
| `fetchExamGet` | GET | `/teaching/exam/get` | `id` |
| `createExam` | POST | `/teaching/exam/create` | `{ courseId, lessonId, title, scoreRatio }`；`data` 可为 Long id |
| `updateExam` | PUT | `/teaching/exam/update` | `{ id, courseId?, lessonId?, title?, scoreRatio?, status? }` |
| `deleteExam` | DELETE | `/teaching/exam/delete?id=` | |

**ExamVO 占位字段**

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` / `examId` | long | 前端用 `resolveExamId` 兼容二者 |
| `courseId` | long | |
| `lessonId` | long | 须对应 `type=2` 课堂，UK |
| `title` | string | |
| `scoreRatio` | int | 1–100；同课程之和 ≤ 100 |
| `status` | int | `0` 配置中 / `1` 可开考 / `2` 进行中 / `3` 已结束 |
| `weekIndex` / `lessonWeekIndex` | int | 列表展示用（可选，可由 lesson 联表） |

**错误**：占比超限时请返回可读 `msg`（建议含「已占用 x%，剩余 y%」）；前端也会识别文案中的 `exam_ratio_exceeded` /「剩余」。

### 2.2 考核项 `teaching_exam_item`

| 前端方法 | 方法 | 路径 | 主要参数 |
|----------|------|------|----------|
| `fetchExamItemListByExam` | GET | `/teaching/exam-item/list-by-exam` | `examId` |
| `fetchExamItemGet` | GET | `/teaching/exam-item/get` | `id`（若无此接口，编辑页会回退用列表项） |
| `createExamItem` | POST | `/teaching/exam-item/create` | `{ examId, itemName, maxScore, weight, algoType, sortOrder }` |
| `updateExamItem` | PUT | `/teaching/exam-item/update` | 含 `id` + 同上字段 |
| `deleteExamItem` | DELETE | `/teaching/exam-item/delete?id=` | |

| 字段 | 说明 |
|------|------|
| `itemName` | 名称 |
| `maxScore` | 满分 |
| `weight` | 项内权重；同 `examId` 之和 **= 100**（服务端强制） |
| `algoType` | `1` 动作识别，`2` 落点检测 |
| `sortOrder` | 排序 |

### 2.3 资料 `teaching_exam_item_material`

| 前端方法 | 方法 | 路径 | 说明 |
|----------|------|------|------|
| `fetchExamItemMaterialList` | GET | `/teaching/exam-item-material/list-by-item` | 查询参数 **`examItemId`** |
| `createExamItemMaterial` | POST | `/teaching/exam-item-material/create` | 元数据 |
| `updateExamItemMaterial` | PUT | `/teaching/exam-item-material/update` | |
| `deleteExamItemMaterial` | DELETE | `/teaching/exam-item-material/delete?id=` | |
| `uploadExamItemMaterialFile` | POST multipart | 现网 `/teaching/plan-material/upload`，失败则旁路 `/teaching/exam-item-material/upload` | 取文件 URL |
| `uploadAndCreateExamItemMaterial` | 组合 | upload → 旁路 `exam-item-material/create` | 元数据写入考试资料表 |

**create 体占位**

```json
{
  "examItemId": 1,
  "materialType": 1,
  "imageUrl": "",
  "videoUrl": "",
  "duration": null,
  "title": "",
  "description": "",
  "sort": 0
}
```

`materialType`：`1` 图片，`2` 视频。

**上传注意（2026-08-13）**

- 优先现网 `plan-material/upload`（与教学相同，文件落 `pic-video`）。`data` 常为 Long id，前端再 `GET /teaching/plan-material/get` 或 `list-by-item` 取 URL。
- 现网 upload 可能**顺带**插入 `teaching_item_material`；考试列表只认 `teaching_exam_item_material`。
- 现网失败则旁路本地落盘（`file-storage/`），**不要**再走芋道 `FileApi` / 七牛示例桶（会 403「系统异常」）。
- 改完旁路 Java 必须重新 `package` 并杀掉旧 48081 进程再启动。

## 3. 前端校验（与设计 §1.6）

| 规则 | 位置 |
|------|------|
| 本场 `scoreRatio` ≤ 剩余占比 | `exam-create` 提交前；最终以后端为准 |
| 进入考场：≥1 考核项 | `validateExamReadyForRoom` |
| 资料 | **选填**（阶段一不拦截无资料） |
| 项内权重合计 = 100 | 进入考场强制；编辑页弱提示（可先保存未凑满） |
| 同一 lesson 重复建考 | 依赖后端 UK；前端无额外拦截 |

## 4. 按后端实况改前端的清单

只需改 [`services/examApi.js`](../services/examApi.js) 时优先：

1. **路径改名**：改各 `teachingGet` / `teachingJsonRequest` 的 path 字符串。  
2. **列表字段 snake_case**：在 `resolve*` / 页面赋值处加映射，或在 API 层 normalize。  
3. **create 返回结构**：扩展 `normalizeCreateLongId`。  
4. **课堂列表**：若正式提供 `/teaching/lesson/list-by-course`，改 `fetchLessonsByCourse` 内路径，并可去掉前端 `type` 过滤。  
5. **上传**：现网 / 旁路双路径已在 `uploadExamItemMaterialFile`；合回现网后可去掉旁路分支。  
6. **资料列表参数**：若后端用 `itemId` 而非 `examItemId`，改 `fetchExamItemMaterialList` 的 query。

页面一般不用动，除非 VO 缺展示字段。

## 6. 联调自测建议

1. 建考试课堂（`type=2`）→ 建考试占比 40 → 列表可见。  
2. 再建物占比 70 → 应失败（剩余 60）。  
3. 再建 60 → 成功，合计 100。  
4. 无考核项点「进入考场」→ 拦截。  
5. 有项无资料 → **允许**进入考场拦截逻辑（资料选填）。  
6. 权重合计 ≠100 → 进入考场拦截。  
7. 上传视频后查 **`teaching_exam_item_material`**（不是 `teaching_item_material`）。

阶段一**不测**大屏与算法。
