## 3. 成绩状态

`teaching_exam_score.status`：

| 值 | 含义 |
|----|------|
| 0 | 未考 |
| 1 | 计算中 |
| 2 | 待审核 |
| 3 | 已完成 |
| 4 | 失败 |
| 5 | 缺考 |

重考覆盖：同一 `student_id + exam_item_id` 再提交则覆盖。缺考/重开是**本场学员级**（该生所有考核项）。

## 4. API（48081，`/admin-api`）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/teaching/exam-score/submit-video` | multipart `file` + `examId, examItemId, studentId, classId?, videoDuration?` |
| GET | `/teaching/exam-score/list-by-exam?examId=` | 本场成绩 |
| GET | `/teaching/exam-score/get?id=` | 详情 |
| PUT | `/teaching/exam-score/review` | `{ id, finalScore, comment }` → 已完成 |
| POST | `/teaching/exam-score/algo-callback` | Header `X-Algo-Callback-Token`；body 为算法 JSON |
| POST | `/teaching/exam-score/retry?id=` | 失败且原片仍在则再入队 |
| POST | `/teaching/exam-score/mark-absent` | `{ examId, studentId, classId? }` |
| POST | `/teaching/exam-score/restart-student` | `{ examId, studentId }` |

后台每 5 秒轮询算法 `GET /api/v1/badminton/results/{requestId}`。配置见 `application-local.yaml` 的 `yudao.exam.algo`。

改 Java 后必须重新 `package` 并杀掉旧 48081 再启动。

## 5. 中继学员状态

`ExamineeView.status`：`waiting | testing | done | absent`。

新增命令（仅 `running`）：

- `markExamineeAbsent { classStudentId }`
- `restartExaminee { classStudentId }`

`advanceExaminee` 跳过 `done` / `absent`。大屏队列不展示缺考/已完成。自检：`cd relay-server && npm run verify:exam`（需中继已启动）。改中继后必须重启。
