阶段二**不改现网 Java**。考核项与资料仍走旁路 `48081`；学员名册走现网 `GET /teaching/class-student/list-by-class`（`48080`）。成绩闭环见 [`考试模式阶段三对接说明.md`](./考试模式阶段三对接说明.md)。

## 1. 用户路径

```text
班级详情 → 考试列表
  → 进入考场（validateExamReadyForRoom：≥1 考核项且项内权重合计 = 100%）
  → exam-room 连接中继（默认房间 1001 / 令牌 2002）
  → setExamBriefing：大屏左栏学员队列（前 6 人）+ 右栏考核项/视频/资料描述
  → 开始考试：同一布局，队列滚动待考前 6 人
  → 下一名 / 点选当前考生
  → 结束考试 → 退出考试态（否则上课 setPlan 会被 mode_conflict）
```

旧页 `exam-setup` / `exam-session` / `exam-active` 仍保留，主路径不再进入。

## 3. 中继命令

`{"type":"command","name":"<name>","payload":{...}}`

| name | payload | 效果 |
|------|---------|------|
| `setExamBriefing` | `{ examId, examTitle, items[], currentItemId?, mediaBearerToken?, mediaTenantId? }` | `mode=exam`，`examPhase=briefing` |
| `setExamItem` | `{ id }` | 仅 briefing：切当前项并停播 |
| `setExamVideoPlaying` | `{ playing }` | 仅 briefing |
| `startExam` | `{ examinees[], currentExamineeId? }` | `running`，停播 |
| `setCurrentExaminee` | `{ classStudentId }` | 仅 running（缺考不可点选） |
| `advanceExaminee` | `{}` | 当前 `done`，下一名可考 `testing`（跳过 done/absent） |
| `markExamineeAbsent` | `{ classStudentId }` | 该生 `absent`；当前考生则切下一名 |
| `restartExaminee` | `{ classStudentId }` | 该生 `testing` 并设为当前 |
| `finishExam` | `{}` | `finished` |
| `exitExamMode` | `{}` | 回 `training`（保留媒体令牌） |

考试态下 `setPlan` / `pause` / `resume` / `setCurrentItem` / `setItemDuration` / `resetBlockTimer` / `toggleVideo` / `setVideoPlaying` 回：

```json
{ "type": "error", "code": "mode_conflict", "message": "当前为考试模式，请先结束考试" }
```

状态不变、不广播。`setMediaAuth` 仍可用。考试态不推进训练用 `sessionElapsedSec`。

自检（中继已启动）：

```bash
cd badminton-teacher/relay-server
npm run verify:exam
```

---

## 4. 重连策略

- 大屏断线点「重试」：`joined.state` 含完整考试字段，视图应与离开前一致。
- 教师端 `joined` 后：始终 `setMediaAuth`。若快照已是**本场**考试且 phase 为 `running` / `finished`，**不再**下发 `setExamBriefing`。否则下发讲解。
- 离开 `exam-room` 会发 `exitExamMode`，避免卡住上课遥控。

## 5. 局域网联调

三端同一房间（默认 `1001` / `2002`）：

1. `cd badminton-teacher/relay-server` → `npm run dev`（端口 3456，改逻辑后必须重启）。
2. `cd gym_screen` → `npm run dev` → 浏览器打开 `http://localhost:5173`。
3. 教师端微信开发者工具（可关域名校验）：考试列表 → 进入考场；开发者工具连 `ws://127.0.0.1:3456`。真机填电脑局域网 IP，可点「探测中继」。
4. 考核项资料若在现网 `pic-video`，教师须已登录（`mediaBearerToken`）。

验收对照（设计 §2.6）：

| # | 期望 |
|---|------|
| 2.1 | 大屏项列表 + 可播资料 |
| 2.2 | 切项后面板媒体切换 |
| 2.3 | 开始考试切学员视图并停播 |
| 2.4 | 下一名：当前 done、下一名 testing |
| 2.5 | 考试态发 `setPlan`（上课遥控或 `verify:exam`）→ `mode_conflict`，大屏不变 |
| 2.6 | 大屏重试后状态一致；教师重连 running 不重置 briefing |
| 2.7 | 无考核项或权重合计 ≠100% → 列表拦截，不进考场 |
